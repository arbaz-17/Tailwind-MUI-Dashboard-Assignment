# Material UI Dashboard

## Overview

This folder contains the Material UI implementation of the project dashboard. It combines the dashboard shell, responsive layout, theme handling, sidebar behavior, and MUI-specific styling.

## Responsibilities

- Compose the complete Material UI dashboard.
- Manage light/dark theme state.
- Manage mobile navigation and sidebar collapse/expand behavior.
- Apply the custom MUI theme across dashboard components.
- Render dashboard metrics, charts, status information, and recent projects.

## Key Concepts

- Material UI components
- ThemeProvider
- `sx` styling
- Responsive breakpoints
- Dark/light themes
- Component composition
- Local UI state

## Structure

- `MuiDashboard.tsx` — Main Material UI dashboard composition and UI state.
- `components/` — Reusable dashboard UI components.
- `theme/` — Custom Material UI theme configuration.
