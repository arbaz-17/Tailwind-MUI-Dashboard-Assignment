# Types

## Overview
This folder contains the shared TypeScript types used across the dashboard assignment. It keeps the Tailwind CSS and Material UI implementations working with the same data structures.

## Key Concepts
- Type aliases and interfaces
- Shared type safety
- Reusable data models
- Consistent contracts between implementations

## File
- `dashboard.ts` — Defines types for projects, statuses, priorities, departments, navigation items, KPI metrics, chart data, and status summaries.

## Role in the Assignment
These shared types are used by the mock data and both dashboard implementations, helping keep the comparison consistent and strongly typed.
