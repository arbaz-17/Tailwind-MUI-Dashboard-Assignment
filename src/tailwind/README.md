# Tailwind Dashboard

## Overview

This folder contains the Tailwind CSS implementation of the project dashboard. It combines the dashboard shell, responsive layout, theme handling, sidebar behavior, and Tailwind-specific styling.

## Responsibilities

- Compose the complete Tailwind dashboard.
- Manage light/dark theme state.
- Manage mobile navigation and sidebar collapse/expand behavior.
- Render dashboard metrics, charts, status information, and recent projects.

## Key Concepts

- Tailwind CSS utility classes
- Responsive design
- Dark mode
- Component composition
- Local UI state
- Accessible navigation
- Scoped styling

## Structure

- `TailwindDashboard.tsx` — Main Tailwind dashboard composition and UI state.
- `components/` — Reusable dashboard UI components.
- `styles/tailwind.css` — Tailwind theme tokens, dark-mode variant, and scoped reset.
