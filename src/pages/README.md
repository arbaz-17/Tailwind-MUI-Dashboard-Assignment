# Pages

## Overview
The `pages` folder contains the comparison landing page for the assignment. It acts as the entry point where users can choose between the Tailwind CSS and Material UI dashboard implementations.

## Responsibilities
- Present the Week 10 assignment comparison.
- Provide navigation to `/tailwind` and `/mui`.
- Show brief assignment information in a simple responsive layout.

## Files
- `ComparisonLandingPage.tsx` — Renders the comparison landing page, dashboard selection cards, and assignment information.
- `ComparisonLandingPage.module.css` — Contains the scoped styles, dark theme, responsive layout, card styling, and interaction states for the page.

## Project Role
This page is intentionally independent from both Tailwind CSS and Material UI so it can serve as a neutral entry point for comparing the two dashboard implementations.
